# 🎧 Virtual Alliance Boarding Audios

Bem-vindo ao **Virtual Alliance Boarding Audios**!

---

## 📌 Primeira execução

Ao iniciar o aplicativo pela primeira vez, ele criará automaticamente a seguinte estrutura de pastas em **Documentos**:

```
Documentos/
└── Virtual Alliance Boarding Audios/
    └── audios/
```

---

## 🎵 Adicionando os áudios

1. Abra a pasta:

```
Documentos/Virtual Alliance Boarding Audios/audios
```

2. Copie para as respectivas pastas todos os áudios que deseja utilizar.

### Formato suportado

✅ Apenas arquivos **.mp3**

Exemplo:

```
Documentos/
└── Virtual Alliance Boarding Audios/
    └── audios/
        └── Embarque/
            └── Embarque.mp3
```

---

## 🔄 Após adicionar os arquivos

Depois de copiar os arquivos `.mp3` para a pasta:

- Feche o aplicativo (ou clique em atualizar).

Os áudios serão carregados automaticamente e aparecerão na lista do aplicativo.

---

## ❗ Importante

- Apenas arquivos com extensão **.mp3** serão reconhecidos.
- Não altere o nome da pasta **audios**.
- Caso nenhum áudio seja exibido, verifique se os arquivos estão realmente dentro da pasta:

```
Documentos/Virtual Alliance Boarding Audios/audios
```

e se possuem a extensão **.mp3**.

---

## ✅ Configuração concluída

Após realizar esse procedimento uma única vez, basta adicionar ou remover arquivos `.mp3` dessa pasta sempre que desejar atualizar a lista de áudios disponível no aplicativo.
